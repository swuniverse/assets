# Assets

Diese Assets basieren auf dem ursprünglichen Repository [st-universe/assets](https://github.com/st-universe/assets) und stehen unter der MIT-Lizenz.

## Struktur

/planets: Bilder für die 10x10 Grids (getrennt nach Typen wie Wüste, Eis, Wald).
/ships: Top-Down Icons für die Sektor- (120x120) und System-Karten (20x30).
/ui: Frames, Buttons und Hologramm-Overlays für das Frontend.
/research: Icons für den technologischen Fortschrittsbaum.
