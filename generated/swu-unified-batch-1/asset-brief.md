# Star Wars Universe asset generation brief

Generate a new unified icon set for the current UI-missing building/resource families.

## Output contract
- Produce contact-sheet PNGs suitable for splitting into individual **256x256 PNG** game UI icons.
- No text inside icons. No logos. No protected character likenesses.
- Square icon cells, centered subject, transparent or very dark neutral background, high readability at 48px.
- Consistent new style across buildings and resources: dark sci-fi strategy UI, clean isometric/3D icon language, rim lighting, subtle holographic blue/amber accents, physically distinct silhouettes.
- Include a machine-readable manifest listing each cell index, kind, id/family slug, and label.

## Full scope counts
- Missing building families: 136
- Missing visible type-1 commodities: 309

Because this is a large batch, start with the UI-missing priority set below. Use family icons for buildings; variants/levels share a family icon.
